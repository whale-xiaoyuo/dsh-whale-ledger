## 录屏要点（自己拍的时候）

1. 先露一下侧栏那头小鲸鱼，点开
2. 慢慢划到「会话排行」，念两个真实数字（¥1.05 / 24 轮 / 1486 万 token）
3. 指一下「谁醒着」的四个状态：活跃 / 潜水 / 沉睡 / 暂停
4. 点「服务健康」三个绿点
5. 按 Esc 回到会话 —— 证明它不是个黑洞
6. 最后：`WHALE_LEDGER_NO_CORE=1` 重启，展示降级（金额标「估算」、额度条消失）
